# Prometix Free Tools

**English** | [Srpski](README.sr.md)

Free, open-source SEO and marketing tools by [Prometix](https://prometix.net). Each tool lives in its own folder with its own documentation.

## Tools

| Tool | What it does | Requirements |
| --- | --- | --- |
| [Prometix Keyword Harvester](prometix-keyword-harvester/) | Collects keyword ideas from Google Autocomplete (Suggest) and exports them to TXT, CSV and JSON, sorted by relevance. | Node.js 18+ |

## Getting started

```bash
git clone https://github.com/ralevuk/prometix-free-tools.git
```

Then open the folder of the tool you want and follow its README.
