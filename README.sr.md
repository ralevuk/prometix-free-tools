# Prometix Free Tools

[English](README.md) | **Srpski**

Besplatni SEO i marketing alati otvorenog koda iz [Prometix](https://prometix.net)-a. Svaki alat je u svom folderu, sa sopstvenom dokumentacijom.

## Alati

| Alat | Šta radi | Potrebno |
| --- | --- | --- |
| [Prometix Keyword Harvester](prometix-keyword-harvester/README.sr.md) | Prikuplja ideje za ključne reči iz Google Autocomplete-a (Suggest) i izvozi ih u TXT, CSV i JSON, sortirane po relevantnosti. | Node.js 18+ |

## Početak

```bash
git clone https://github.com/ralevuk/prometix-free-tools.git
```

Zatim otvorite folder željenog alata i pratite njegov README.
